# Hisham Labs

Hisham Labs is the official product lab portfolio for Hisham Ahmad, showcasing working cloud, operations and travel prototypes.

## Featured Projects

- CloudShift
- CarWashOS
- RareCruise

## Technology Stack

- React
- TypeScript
- Vite
- CSS

## Local Development

```bash
pnpm install
pnpm dev
```

## Production Build

```bash
pnpm build
```
